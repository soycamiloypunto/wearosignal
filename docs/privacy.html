Política de Privacidad — WearOSignal

Paquete: com.wearosignal.app · Desarrollador: Cristian Camilo · Contacto: cktv8822@gmail.com · Última actualización: noviembre de 2026

1. Recolección de datos

WearOSignal no recopila, almacena ni vende datos personales de los usuarios. El desarrollador no opera servidores intermedios ni recibe copias de tus mensajes, contactos, audios o credenciales. La aplicación no contiene publicidad, analíticas ni SDKs de telemetría de terceros.

2. Comunicación directa con Signal

WearOSignal funciona como un cliente independiente y no oficial de Signal (dispositivo vinculado). Toda la comunicación de red se realiza directamente entre tu reloj Wear OS y los servidores oficiales de Signal (*.signal.org) mediante cifrado de extremo a extremo usando el protocolo Signal (libsignal).

3. Uso de permisos del dispositivo

  • Micrófono (RECORD_AUDIO): se usa únicamente cuando grabas una nota de voz dentro de un chat. El audio se cifra y envía a través de Signal CDN y el archivo temporal se elimina tras el envío.
  • Contactos (READ_CONTACTS): opcional; se usa solo si solicitas buscar contactos de tu reloj registrados en Signal mediante el servicio privado CDSI (SGX) de Signal.
  • Notificaciones (POST_NOTIFICATIONS): se usa para mostrar alertas de mensajes entrantes en tu reloj.

4. Almacenamiento local, cifrado y eliminación

Tus credenciales y claves de sesión se guardan únicamente en el almacenamiento privado de tu reloj cifradas con Android Keystore (AES-256-GCM). Los archivos multimedia en caché se eliminan automáticamente tras 7 días (límite de 64 MB). Puedes borrar todos tus datos locales en cualquier momento desde Ajustes → Desvincular reloj o desinstalando la aplicación.

5. Licencia y código fuente

WearOSignal es software libre bajo licencia GNU AGPLv3. El código fuente completo está disponible en github.com/soycamiloypunto/wearosignal. No está afiliado ni respaldado por Signal Messenger, LLC.
